# Запуск Nginx через Docker Compose

## Запуск
В папке с `compose.yaml` выполнить:
```bash
docker compose up -d
```
Открыть в браузере `http://127.0.0.1:8081`. Должна появится страница **Welcome to nginx!*

## Проверка
```bash
curl -i http://localhost:8081/
```
Результат проверки — `200 OK`.

Порт `8081` находится на Mac. Docker перенаправляет запросы с него на порт `80` внутри контейнера, где работает Nginx.
